Keep the file name the same as the job.

## Closing Notes for GanttProject Software

Treat GanttProject Software as the chart for one job, not as a dump of every idea you have ever had. Open GanttProject when the dates matter. Keep the active rows few. Move finished work out of the way. Let old drafts of the file stay quiet.

If you change desks, copy the project file with you. If you show a teammate, show them the date scale first. After that, GanttProject Software usually needs almost no explanation.
